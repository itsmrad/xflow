xflow doesn't run a speech model on your machine. It sends each recording to the provider you choose, using your key. You pay the provider directly; xflow never meters you.

<ProviderTable />

## Pick one

```sh
xflow providers list
xflow providers info groq
xflow models groq            # marks the selected and default model
xflow providers use deepgram
```

## Store the key

```sh
xflow key set groq           # hidden input
xflow key status
xflow key remove groq
```

Keys are encrypted in xflow's own keystore (two 0600 files, see [Privacy and security](/docs/privacy-and-security#what-is-stored)) — never in `config.toml`, and never in the system Keychain, so storing or reading a key shows no OS prompt. Keys that older builds left in the Keychain or Secret Service move over once; `xflow key status` shows where each key comes from.

Headless setups can use an environment variable instead (`GROQ_API_KEY`, `OPENAI_API_KEY`, …). A variable exported in your shell isn't visible to a launchd or systemd service, so prefer `xflow key set` there.

## Check it

```sh
xflow providers test groq
```

A non-billable credential and reachability check. It uploads no audio.

## Vocabulary hints

Your [dictionary](/docs/using/dictionary) words are sent as recognition hints. Each provider has its own limit, and xflow checks it before upload rather than letting the provider fail. `xflow doctor` reports when your list doesn't fit.

With `stt.domain_hints` on (the default), xflow fills the room your words leave with shipped terms for the `[vocab]` domains: developer and business terms by default, spreadsheet functions in Excel, Numbers and LibreOffice Calc, developer terms first in terminals and editors, and finance terms if you turn them on. These are public product and industry names (Claude, kubectl, Supabase, XLOOKUP, EBITDA), not your data. They only bias recognition and never rewrite text. At most 100 are offered. On Whisper (Groq and other prompt-based providers) they fill at most half the prompt, about 20 terms: a longer list added latency and cost sentence punctuation. OpenAI keywords, Gemini and Mistral take up to 30; if a provider rejects the list, xflow retries once with your words only. ElevenLabs, Deepgram and AssemblyAI bill keyterms extra, so they get your words only.

## Cleanup is separate

AI cleanup (punctuation, filler words, per-app styles, command mode) uses a chat model, configured under `[cleanup]` with its own provider. It's off by default (`mode = "raw"`). If cleanup fails, you get the original transcript.
