Generated from `config/default.toml`. Do not edit by hand: run `bun scripts/gen-docs.ts` in `apps/web`.

The file lives at `~/.config/xflow/config.toml`. `xflow config path` prints the exact location. Change a value with `xflow config set <key> <value>`; the daemon reloads it.

xflow configuration. Edit here, with `xflow config set <key> <value>`, or in the TUI.
Secrets are read from OS credential storage or environment variables, never this file.
Overlay look is managed with `xflow overlay`; Linux shortcuts use GNOME settings.

## [stt]

| Key | Default | Description |
| --- | --- | --- |
| `stt.provider` | `"groq"` | `xflow providers` lists every provider |
| `stt.model` | unset | `xflow models` lists models; unset = provider default; e.g. `"whisper-large-v3-turbo"` |
| `stt.endpoint` | unset | full URL override; e.g. `"https://api.groq.com/openai/v1/audio/transcriptions"` |
| `stt.protocol` | unset | wire protocol for provider = "custom"; e.g. `"openai"` |
| `stt.api_key_env` | unset | e.g. `"GROQ_API_KEY"` |
| `stt.language` | unset | ISO-639-1; unset = automatic detection; e.g. `"en"` |
| `stt.vocabulary` | `[]` | extra recognition hints (dictionary.words are added too) |
| `stt.timeout_secs` | `30` |  |

## [formatting]

| Key | Default | Description |
| --- | --- | --- |
| `formatting.snap_to_dictionary` | `true` | Snapping runs before dictionary.replacements, so a replacement's `from` must match the snapped spelling ("xflow", not "x flow", when xflow is saved). restore dictionary/vocabulary spellings locally; false disables snapping |
| `formatting.remove_fillers` | `true` |  |
| `formatting.fillers` | `["um", "umm", "uh", "uhm", "er", "erm", "ah", "hmm", "mm", "mhm"]` |  |
| `formatting.spoken_punctuation` | `false` | "comma", "period", "new line", ... become punctuation |
| `formatting.lists` | `true` | "one ..., two ..., three ..." / "bullet ..." become a list (never in terminals) |

## [[snippets]]

Voice snippets: say the trigger, get the text.

Not set by default. Example:

```toml
[[snippets]]
trigger = "my email"
text = "me@example.com"
```

## [[styles]]

Per-app styles: the first style whose apps match the focused app id wins.

Not set by default. Example:

```toml
[[styles]]
name = "chat"
apps = ["slack", "discord", "telegram"]
mode = "light"
prompt = "Casual tone. Lowercase is fine."
```
