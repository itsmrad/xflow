Generated from `xflow --help` (xflow 0.2.1-beta). Do not edit by hand: run `bun scripts/gen-docs.ts` in `apps/web`.

`--json`, `--quiet`, `--color auto|always|never` and `--config PATH` work on every command. JSON goes to stdout; errors are JSON objects on stderr with `error`, `hint` and `exit_code`.

## xflow

```text
Fast dictation for developers, from your terminal

Usage: xflow [OPTIONS] <COMMAND>

Commands:
  mcp          Share read-only dictation context with local MCP clients
  ask          Ask a question about your dictations; excerpts go to the [ai] provider
  setup        Set up a provider, microphone and optional desktop integration
  start        Begin recording (bind to shortcut press for push-to-talk)
  stop         Stop recording and begin transcription
  toggle       Start or stop hands-free recording
  cancel       Discard the active recording or pending transcription
  status       Show daemon state, provider, model, version and timings
  watch        Subscribe to daemon events until interrupted
  listen       Print dictation to stdout without changing the desktop
  transcribe   Transcribe an audio file without a running daemon
  last         Print the last transcript
  copy         Copy the last transcript [alias: copy-last]
  paste        Insert the last transcript into the focused app [alias: paste-last]
  retry        Transcribe the failed dictation kept by privacy.keep_failed_audio again and print it
  history      Browse, search and export local dictation history
  meeting      Transcribe meeting audio, or import, list, search, show, export or delete a private meeting transcript
  config       Inspect or edit validated, comment-preserving TOML configuration
  providers    List providers, inspect capabilities and select a default
  models       List provider models, inspect the on-device model and hardware, or install/remove it
  key          Manage provider credentials in OS credential storage; a custom cleanup endpoint uses the `cleanup` entry
  dictionary   Manage vocabulary and text replacements
  snippets     Manage spoken shortcuts that expand to saved text
  styles       Manage cleanup styles selected by focused application
  overlay      Inspect and change native overlay settings
  devices      List available microphone input devices
  stats        Show local dictation statistics
  doctor       Diagnose configuration and desktop dependencies without recording
  daemon       Control the systemd/launchd user daemon or view its logs
  service      Install or uninstall the graphical-session user service
  extension    Install or manage the bundled GNOME Shell extension
  completions  Generate shell completion scripts
  version      Show CLI and, when available, daemon versions
  tui          Open the terminal control centre (also plain `xflow` in a terminal)
  help         Print this message or the help of the given subcommand(s)

Options:
      --json           Emit machine-readable JSON (watch emits one object per event)
  -q, --quiet          Suppress confirmations; requested data and errors remain visible
      --color <COLOR>  Control colour in human output [default: auto] [possible values: auto, always, never]
      --config <PATH>  Read/write an alternate configuration file
```

### xflow meeting process

Copy WAV audio into private storage and transcribe it into a meeting.

```text
Copy WAV audio into private storage and transcribe it into a meeting.

Each file is one source, such as the microphone and the remote side, starting at the same moment. Your files are only read. The private copy is deleted as each part's text is stored; audio not yet transcribed is kept until `retry` succeeds or you delete the meeting, never expired. Uses the configured speech-to-text provider, never its backup.

Usage: xflow meeting process [OPTIONS] <FILES>...

Arguments:
  <FILES>...
          One or two WAV files, up to 3 hours each

Options:
      --json
          Emit machine-readable JSON (watch emits one object per event)

      --title <TITLE>


  -q, --quiet
          Suppress confirmations; requested data and errors remain visible

      --wait
          Stay and show progress until transcription ends. Without it the command returns once the audio is stored; transcription continues in the background even if this terminal closes

      --color <COLOR>
          Control colour in human output

          [default: auto]
          [possible values: auto, always, never]

      --config <PATH>
          Read/write an alternate configuration file

  -h, --help
          Print help (see a summary with '-h')
```
