Free xflow uses your own provider key, with no limits. Pro is for when you'd rather not have a provider account at all: xflow's server does the transcription and cleanup with xflow's key.

| | Free | Pro |
| --- | --- | --- |
| Price | $0 | $5/month |
| Dictation | Unlimited, your key | Unlimited, our key |
| Speech providers | 10, or a local server | Hosted |
| AI cleanup | Optional, your key | Included |
| Features | Everything | Everything in Free |

<Callout type="note" title="Coming with the Pro launch">
Pro isn't live yet. Signing in from the CLI (`xflow login`) and the hosted endpoint arrive with the launch, and these docs will cover both then.
</Callout>

## Fair use

Pro is unlimited for people. To keep it that way, the server caps concurrent requests and per-minute bursts, so scripts can't drain the shared key. You won't hit the limit by talking.

## Billing

Payments are handled by Dodo Payments, the merchant of record. You can cancel any time from your dashboard; Pro stays on until the end of the period you paid for, and xflow then drops back to Free with your own key, if you've set one.
