xflow is installed and running

A Terminal window now opens guided setup. It walks you through everything:

  1. Permissions. It opens System Settings at Input Monitoring, then Accessibility, then Microphone. Each time, find xflowd in the list and switch it on; you never need to add it yourself. Setup moves on by itself. If the Keychain asks, click Always Allow.
  2. Speech service. Add your speech key and pick your microphone (first install only).
  3. Try it. Hold Fn and say something.

Fn opens emoji or dictation instead? System Settings › Keyboard › “Press 🌐 key to” › Do Nothing.
Use it: hold Fn to dictate. Double-tap Fn for hands-free, then press Fn again to stop.
Setup again or check-up: xflow tui
Uninstall: xflow service uninstall && sudo rm -r /usr/local/bin/xflow /usr/local/bin/xflowd /usr/local/share/xflow
